stacked passes · prototype

Scroll, and the cards fan into a deck.

Each pass parks 46px below the previous one (the “peek”), near-fullscreen, scaling and dimming slightly as it settles behind the next. Pure CSS — position: sticky for the stack, a scroll-driven view() timeline for the depth. No JS, no build.

01 — index↓

The peek is the whole trick.

Incremental top values keep every card's top edge visible as the stack builds, instead of one card fully replacing the last.

02 — writing↓

Near-fullscreen, not column-width.

Cards run to ~78vh and a generous max-width so they read as passes, not content boxes parked in a feed.

03 — work↓

Depth without gloss.

A subtle scale + brightness drop sells “behind.” Flat color fields keep it quiet rather than skeuomorphic.

04 — notes↓

Graceful everywhere.

Browsers without scroll-driven animations just skip the scale; the sticky stacking still works. Reduced-motion turns it all off.

05 — contact●

Tune the feel with two numbers.

Change --peek for how much shows through, and --pass-h for how full-screen it gets. Everything else follows.
